How I approach problems

Understand first. Analyse second. Build with purpose.

I like working at the intersection of business questions and practical execution — starting with the problem, using data and frameworks to structure it, and turning the analysis into an actionable direction.

01 · Frame

Define the problem

  • Clarify the objective
  • Understand the audience
  • Identify the decision that needs to be made
02 · Analyse

Find the signal

  • Use data and relevant frameworks
  • Compare alternatives
  • Separate observations from assumptions
03 · Act

Make it practical

  • Translate insights into actions
  • Connect recommendations to measurable goals
  • Build and test where possible
